# 하드웨어 조건 — 먼저 읽어 주세요

## 핵심: Windows Hello 얼굴 인식에는 **IR(적외선) 카메라**가 필요합니다

Windows Hello 얼굴 인식은 사진·화면으로 속이지 못하도록 적외선 카메라로 얼굴의 깊이/반사를
확인합니다. 그래서 **일반 RGB 웹캠으로는 켤 수 없고**, 소프트웨어 설정만으로 우회할 방법도 없습니다.
(일반 웹캠 + 얼굴 인식으로 비밀번호를 자동 입력하는 비공식 도구들은 사진 한 장으로 뚫릴 수 있어
이 프로젝트에서는 다루지 않습니다.)

## 삼성 갤럭시 북(Galaxy Book)의 경우

갤럭시 북 시리즈는 대부분 **전원 버튼 일체형 지문 센서**로 Windows Hello를 지원하고,
내장 카메라는 일반 HD/FHD 웹캠인 모델이 많습니다. 모델·세대에 따라 다르므로
제원표보다 `scripts/Check-HelloFace.ps1` 의 결과를 기준으로 판단하세요.

빠른 수동 확인:

1. 설정 > 계정 > 로그인 옵션 을 엽니다.
2. **"얼굴 인식 (Windows Hello)"** 항목이
   - 있고 "설정" 버튼이 눌리면 → 내장 IR 카메라 있음. `Enable-HelloFace.ps1` 로 진행.
   - "이 옵션은 현재 사용할 수 없습니다" 라고 나오면 → IR 카메라 없음(또는 드라이버 문제).
3. 장치 관리자 > 카메라 에 `IR` 이 들어간 장치가 있는지도 확인합니다.

IR 카메라가 있는데 안 보이면: **Samsung Update** 앱에서 카메라/칩셋 드라이버를 업데이트한 뒤 재부팅하세요.

## IR 카메라가 없다면: 외장 Windows Hello 웹캠

USB로 연결하는 **"Windows Hello 지원"** 표시가 있는 웹캠을 쓰면 됩니다. 구매 전 확인할 점:

- 제품 설명에 **Windows Hello 얼굴 인식 지원 / IR 센서** 가 명시돼 있는지
  (단순 "Windows 호환"은 해당 없음)
- 노트북 화면 위에 걸 수 있는 클립형인지
- USB-C / USB-A 포트 종류

연결 후 `Check-HelloFace.ps1` 에서 "Hello 얼굴 장치" 가 OK 로 나오면 됩니다.

## 보안 강화 로그인(ESS)이 켜진 경우

최신 노트북(특히 Copilot+ PC / Secured-core PC)은 **보안 강화 로그인(Enhanced Sign-in Security)** 이
켜져 있을 수 있습니다. 이 경우 내장 센서만 신뢰하므로 **외장 IR 웹캠이 동작하지 않습니다**.

- Windows 11 최신 빌드: 설정 > 계정 > 로그인 옵션 >
  **"외부 카메라 또는 지문 판독기로 로그인"** 을 켭니다. (보안 수준이 한 단계 낮아집니다.)
- 이 프로젝트의 스크립트는 ESS 상태를 **보여주기만** 하고 바꾸지 않습니다.

## 지문은 어떻게 되나요?

얼굴과 지문은 함께 등록해 둘 수 있습니다. 잠금 화면에서 카메라가 얼굴을 먼저 인식하면 바로 풀리고,
안 되면 지문이나 PIN 으로 풀 수 있습니다. 지문을 아예 쓰지 않으려면
설정 > 계정 > 로그인 옵션 > 지문 인식 > **제거** 를 직접 누르세요 (스크립트는 삭제하지 않습니다).
